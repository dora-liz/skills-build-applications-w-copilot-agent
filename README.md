## 🧘 Engineer Wellbeing Timer

This repository includes a simple mental wellbeing app designed for engineers. The app helps maintain healthy work habits by reminding you to take breaks every 20 minutes.

**Features:**
- 20-minute timer with break reminders
- Prompts to take a walk and look away from screen
- Daily statistics tracking
- Browser notifications
- No installation required - just open and use!

**Quick Start:**
```bash
# Open in browser
open wellbeing-app/index.html

# Or run with a local server
cd wellbeing-app
python3 -m http.server 8080
# Then open http://localhost:8080
```

See [wellbeing-app/README.md](wellbeing-app/README.md) for full documentation.
